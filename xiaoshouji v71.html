语音模式

关闭时只显示可展开文字的模拟语音波形，不播放 AI 合成语音；开启并保存后，发送语音才会调用 MiniMax 生成真实音频。真实语音需要填写 API Key。

MiniMax 语音合成

从聊天左侧「＋」菜单发送我方语音；对方的文字回复也可以点「转语音」。

语音世界书

可以专门写角色说话的语气、停顿、情绪与音色要求。保存后作为普通世界书参与提示词注入。

全局 AI 扮演提示词

所有角色共用的规则，会与各联系人自己的人设提示词一起发送给 AI。

MEMORY SYSTEM
记忆中心

先选择记忆如何参与对话，再配置向量检索。记忆内容仍在每个聊天的「聊天设置」中分别管理。

记忆模式

选择全局默认模式，不会删除另一种模式里已经保存的内容。

向量模型连接

可单独填写向量服务地址与密钥；留空时会沿用「模型与 API」中的接口和 Key。

填写向量接口地址和 Key 后点击「拉取模型列表」。模型列表能被获取，不代表每个模型都支持 Embedding；最终以实际接口响应为准。

检索范围

每次回复最多取回多少条相关记忆。数量越大，带入提示词的内容通常越多。

我的资料
点击头像更换
生图 API

关闭后，对方只会发文字；你仍然可以在聊天里上传图片。这里的生图配置与聊天模型 API 分开保存。

标准 GPT Images API 没有通用的 negative_prompt 参数；这里会把反向提示词合并进请求文本。不同中转站支持的尺寸、质量和风格参数可能不同。

可填写官方地址或你有权限使用的第三方中转站地址。中转站须兼容 NovelAI 的图像生成请求和 ZIP 图片响应。

NovelAI 参数会发送给兼容的接口；不同模型/中转站对参数支持不完全一致。浏览器直连也可能受 CORS 限制。
